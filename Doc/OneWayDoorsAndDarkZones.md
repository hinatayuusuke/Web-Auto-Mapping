# 一方通行ドアとダークゾーン

## 一方通行ドア

- Workspace の Edit Tool に、互いに逆向きのドアアイコンを2つ追加。
- `one-way door — allows right / down` は、縦の境界では右、横の境界では下への通行を許可。
- `one-way door — allows left / up` は、縦の境界では左、横の境界では上への通行を許可。
- 選択後、境界を左クリックまたは左ドラッグして配置。緑のドア線に重ねた矢印が通行可能な方向を示す。
- 配置後の方向は地図に固定し、プレイヤーの向きやコピー・貼り付けで反転しない。
- Map モードは矢印と逆方向への移動を止める。通行可能な方向でも、移動先が未探索・範囲外なら移動できない。
- Explore モードは実際の移動の記録を優先するため、逆方向への移動も記録する。通過した一方通行ドアの向きは保持する。
- 別の壁・ドア・通路ツールで上書きすると、一方通行の設定を置き換える。右クリックは従来どおり境界を未探索へ戻す。

## ダークゾーン

- Edit Tool の斜線模様アイコンを選択する。
- 左クリック・左ドラッグで暗闇を設定し、右クリック・右ドラッグで暗闇だけを解除する。
- 未探索マスへの設定時は床として記録する。
- 暗闇は床全体の斜線模様で表示し、宝箱・階段・落とし穴・マーカー・プレイヤーの下に描く。
- 床アイコンと独立しているため、アイコンの配置・交換・削除と暗闇の設定・解除は互いを消さない。
- マス自体を未探索へ戻す操作と範囲消去では、暗闇も消す。通常床ツールでは暗闇を保持する。
- 暗闇は表示と記録用の属性で、移動制限や自動マッピングの停止は行わない。

## 保存と編集

- 一方通行は `edgeIcons` の `kind: one-way` と絶対方向 `direction` に保存する。
- 暗闇は階層の `darkZones` にマスの座標一覧として保存し、床アイコンの枠を使わない。
- 保存・読込、Undo／Redo、階層複製、範囲コピー・切り取り・貼り付け、グリッド拡張・縮小に反映する。
- 範囲貼り付けは上書き。通常床を貼り付けたマスでは、貼り付け先の暗闇を解除する。
- 保存形式のバージョンは v1 を維持。既存データで `darkZones` が省略されている場合は暗闇なしとして読み込む。
- 方向なし、または境界に沿う方向の一方通行データは、正しい移動制限を決められないため読み込みを拒否する。
- 新しい編集ツールや属性を含むデータは、この変更を含むアプリで利用する。
- キーボードショートカットの追加・変更は行わない。
