# 端ループ

- 中央マップの機能アイコン列にある循環矢印ボタンで、有効／無効を切り替える。
- 有効時はボタンを強調表示し、ツールチップに現在の状態と探索モード専用であることを表示する。
- 設定は階層ごとに保持し、保存・読込と Undo／Redo の対象にする。新規階層の初期値は無効。

## 探索時の動作

- 有効時、外周からさらに進むと、同じ行・列の反対端へ移動する。向きとマップのサイズは維持する。
- 出発・到着マスを床にし、通過した出発側・到着側の外周境界を両方とも通路にする。
- 自動補完は既存の設定に従い、移動元・移動先の周囲だけに適用する。途中のマスや境界は変更しない。
- 幅または高さが1の場合、その軸のループでは同じマスに戻り、両側の外周境界を通路にする。
- 無効時は従来どおりマップを自動拡張する。
- 内部の壁に向かう移動、マップモード、手動のマップ拡張は従来どおり。

## 保存データ

- 階層データの `edgeWrapEnabled` に設定を保持する。
- v1 の既存保存データでこの項目がない場合は無効として扱い、移行操作は不要。
- 階層を複製した場合は設定も引き継ぐ。
