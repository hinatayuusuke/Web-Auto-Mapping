# Map モードのドラッグ連続編集 実装案

## 1. 概要

`Map` モードで、マウスボタンを押したままカーソルを動かすことで、セルやエッジへ連続配置 / 連続削除できるようにする。  
左ドラッグは連続配置、右ドラッグは連続削除とし、1 回のドラッグ操作は 1 つの履歴単位として扱う。

## 2. ゴール / 非ゴール

### ゴール

- `Map` モードで左ドラッグによる連続配置を可能にする
- `Map` モードで右ドラッグによる連続削除を可能にする
- ドラッグ 1 回を Undo 1 回で戻せるようにする
- セル編集とエッジ編集がドラッグ中に混ざらないようにする

### 非ゴール

- `Explore` モードでのドラッグ移動
- 補間つきの高精度ブラシ処理
- 範囲選択や矩形塗りつぶし

## 3. 前提・仮定

- 現状 `MapCanvas` はクリック単位でセル / エッジ編集を処理している
- マウス位置から対象を求める判定は既に存在する
- store には単発編集を履歴付きで反映する経路がある
- 右クリック削除は現在も存在するが、単発操作前提である

## 4. 現状整理

- 現状の編集は「1 回クリックした点だけを更新」
- そのため壁線や floor の連続編集では、同じ操作を何度も繰り返す必要がある
- セルとエッジは近接しているため、ドラッグ中に判定対象がぶれると誤編集しやすい
- Undo は単発編集単位で積まれている

## 5. 提案アーキテクチャ

### コンポーネント構成

- `MapCanvas`
  - `pointerdown` または `mousedown` でドラッグ開始
  - `mousemove` で連続適用
  - `mouseup` / `mouseleave` で終了
- store
  - ドラッグ中の更新を 1 スナップショットにまとめる専用経路を持つ

### データフロー / シーケンス

1. `Map` モードでマウス押下
2. 押下地点の対象を判定する
   - セル
   - エッジ
3. その対象種別をドラッグ終了まで固定する
4. 左ボタンなら配置、右ボタンなら削除モードとして保持する
5. `mousemove` ごとに現在地点の対象を判定する
6. 対象種別が開始時と一致する場合だけ編集を適用する
7. 同じドラッグ中に一度処理した座標には再適用しない
8. `mouseup` 時に履歴を 1 回だけ確定する

### 既存パターンへの整合

- 既存の「セルかエッジかを判定して編集する」ロジックは再利用する
- 単発クリックも同じ編集関数を通しつつ、ドラッグ時だけ複数対象へ適用する
- 履歴管理だけは「1 drag = 1 entry」を満たす専用経路が必要

## 6. インターフェース設計

### UI / 操作仕様

- 対象モード: `Map` のみ
- 左ドラッグ: 連続配置
- 右ドラッグ: 連続削除
- ドラッグ開始時に対象種別を固定
  - セルで始めたらセルだけ編集
  - エッジで始めたらエッジだけ編集

### 内部状態

- `isDragging`
- `dragOperation`
  - `paint` | `erase`
- `dragTargetKind`
  - `cell` | `edge`
- `visitedTargets`
  - 同一ドラッグ中に処理済みの座標集合

### エラー / バリデーション

- `Explore` モードならドラッグ編集を開始しない
- 対象判定できない位置では何もしない
- 種別不一致の対象には適用しない

## 7. 実装手順

### Step 1

- `MapCanvas` にドラッグ用のローカル state / ref を追加する

### Step 2

- クリック編集で使っている対象判定と編集処理を、ドラッグからも呼べる形へ切り出す

### Step 3

- `mousedown` でドラッグ開始
  - 操作種別
  - 対象種別
  - 初回対象
  を記録する

### Step 4

- `mousemove` で現在対象へ編集を適用する
  - 同じ対象への重複適用は防ぐ

### Step 5

- `mouseup` でドラッグ編集を終了し、履歴を 1 回として確定する

### Step 6

- `npm run build` と実操作確認を行う

## 8. 非機能要件チェック

### 性能

- 単純なマウス移動ごとの対象更新で十分
- 大量セルの塗りつぶしではないため、まずは補間なしで始める

### セキュリティ

- 影響なし

### 可観測性

- 追加ログは不要

### 互換性

- 既存の単発クリック編集は残す
- 右クリック削除の意味も維持する

### 運用

- 追加運用なし

## 9. リスクと緩和策

- Risk: ドラッグ中にセルとエッジが混在して誤編集しやすい
- Mitigation: 開始時に対象種別を固定し、一致する対象だけ処理する

- Risk: 同じ座標に何度も適用して不要な再レンダーや履歴差分が増える
- Mitigation: `visitedTargets` を持ち、1 ドラッグ中は同一対象を 1 回だけ処理する

- Risk: 速いドラッグで一部の対象を飛ばす可能性がある
- Mitigation: 初版は補間なしで実装し、必要になった時点で線分補間を追加する

## 10. 影響範囲

- `src/components/MapCanvas.tsx`
  - ドラッグ開始 / 継続 / 終了
  - 対象判定と編集呼び出し
- `src/store/appStore.ts`
  - 1 drag = 1 undo を実現するための履歴適用経路
- 必要に応じて `changes.md`

## 11. Definition of Done

- `Map` モードで左ドラッグすると連続配置できる
- `Map` モードで右ドラッグすると連続削除できる
- ドラッグ開始時の対象種別と異なる対象は編集されない
- 1 回のドラッグが Undo 1 回で戻せる
- `npm run build` が成功する
